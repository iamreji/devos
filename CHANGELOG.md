# Changelog

## [1.0.0] — Initial Release

### Added
- Modular installer framework with dependency graph
- Doctor command with health scoring (out of 100)
- Update command for all toolchains
- Backup and restore for dotfiles and configs
- Cleanup command for disk space reclamation
- Zsh configuration with lazy-loaded NVM/Bun (<30ms startup)
- Full Oh-My-Zsh git aliases (100+)
- Docker, npm, pnpm, Rust, Solana, Kubernetes, Terraform aliases
- Starship prompt configuration (Catppuccin Mocha theme)
- Oh-My-Zsh with agnoster theme (zsh-autosuggestions, zsh-syntax-highlighting)
- Docker Engine + Compose + lazydocker module
- Node.js (NVM, latest LTS, pnpm, Bun) module
- Rust toolchain (rustup, cargo-binstall, cargo tools) module
- Solana CLI, Anchor, Foundry module
- NVIDIA driver detection, CUDA toolkit, GPU health module
- Nerd Fonts installer (JetBrains Mono, Fira Code, Cascadia Code, Ubuntu)
- Kitty + Ghostty + WezTerm terminal configs (Catppuccin Mocha theme)
- VS Code settings + extensions
- Cursor editor config
- Neovim (LazyVim-style) with LSP, Treesitter, Telescope
- GNOME desktop tweaks (dark theme, dock, animations)
- Wayland utilities (wl-clipboard, grim, slurp)
- Tmux config (Ctrl-a prefix, Catppuccin theme, vi mode)
- btop and fastfetch configs
- Gitconfig with delta diffs, GPG signing, SSH keygen
- Rollback framework for failed installations
- ShellCheck, YAML lint, and markdown lint CI
